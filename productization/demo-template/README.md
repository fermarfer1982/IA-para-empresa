# Demo template

La demo debe demostrar el flujo operativo sin depender de sistemas ni datos reales de produccion.

## Flujos de demo recomendados

- Consultar estado general de infraestructura.
- Ver incidencias demo.
- Crear un borrador de comunicacion.
- Revisar el borrador y simular envio.
- Consultar Power BI con preguntas de ventas demo.
- Usar voz para abrir una incidencia o preparar un correo.

## Reglas de demo

- No enviar emails reales.
- No modificar SharePoint.
- No modificar Zabbix.
- No usar tokens reales.
- No mostrar datos personales reales.
- No usar capturas con nombres, correos o importes reales si no estan anonimizados.

## Datos esperados

- Incidencias sinteticas.
- Contactos demo con emails de dominio controlado.
- Borradores de comunicacion no enviados.
- Modelo Power BI demo o dataset anonimizado.
- Respuestas de voz predecibles para los flujos comerciales.

## Criterio de demo aceptable

Una persona externa debe poder ver el valor del producto en menos de 10 minutos:

- entender que problema resuelve,
- ver un flujo de principio a fin,
- comprobar que hay controles de seguridad,
- ver integracion con datos de negocio.
