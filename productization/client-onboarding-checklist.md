# Onboarding de nuevo cliente

## Descubrimiento

- Nombre de empresa.
- Dominio corporativo.
- Responsable tecnico.
- Responsable funcional.
- Sistemas a integrar.
- Nivel de acceso permitido.

## Integraciones

- Zabbix: URL, version, permisos, alcance.
- SharePoint: sitio, listas, permisos de lectura/escritura.
- Power BI: workspace, dataset/modelo, permisos.
- Microsoft Graph: permisos concedidos.
- Email: dominios permitidos, cuenta remitente.
- Voz: idioma, escenarios permitidos, acciones bloqueadas.

## Parametrizacion

- Branding.
- Modulos activos.
- Plantillas de correo.
- Reglas de aprobacion.
- Politica de auditoria.
- Usuarios permitidos.

## Seguridad

- Confirmar que los secretos quedan fuera del repositorio.
- Confirmar que los logs no imprimen tokens.
- Confirmar que envio real requiere confirmacion.
- Confirmar que acciones destructivas estan desactivadas salvo contrato explicito.

## Demo

- Cargar datos demo o anonimizados.
- Validar flujos comerciales.
- Preparar guion de presentacion.
- Preparar entorno de restauracion rapida.
