# Guion de demo comercial

Duracion objetivo: 8-10 minutos.

## Apertura

Mensaje:

> Esta demo muestra un asistente operativo para infraestructura, incidencias, comunicaciones y analitica Power BI. Esta version usa datos demo y no ejecuta acciones destructivas.

## Flujo 1 - Estado operativo

1. Abrir dashboard.
2. Mostrar resumen de riesgos, incidencias y servicios.
3. Explicar que el panel puede trabajar con datos live o demo.

Valor mostrado:

- Visibilidad centralizada.
- Menos saltos entre herramientas.
- Lectura operativa rapida.

## Flujo 2 - Incidencia y comunicacion

1. Abrir una incidencia demo.
2. Pedir por voz o chat: `prepara email al creador`.
3. Mostrar borrador creado.
4. Revisar destinatario, asunto y cuerpo.
5. Mostrar que el envio real esta bloqueado en demo.

Valor mostrado:

- Trazabilidad.
- Reduccion de trabajo manual.
- Control de seguridad antes de enviar.

## Flujo 3 - Power BI

Preguntas sugeridas:

- `cuanto hemos vendido este año`
- `ventas por mes en 2025`
- `las dos variedades mas vendidas en 2024`
- `productos menos vendidos en 2025`

Valor mostrado:

- Preguntas naturales sobre modelo semantico.
- Tabla legible.
- DAX visible si hace falta auditoria.

## Flujo 4 - Voz

Comandos sugeridos:

- `consulta Power BI, top 10 clientes por ventas este año`
- `prepara correo para Fernando`

Valor mostrado:

- Operativa asistida.
- Voz como entrada, pantalla como verificacion.
- No se envia nada sin confirmacion visual.

## Cierre

Mensaje:

> La misma base se adapta por cliente mediante configuracion: conectores activos, branding, dominios permitidos, Power BI y plantillas de comunicacion.
